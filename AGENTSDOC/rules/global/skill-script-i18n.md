# Skill 脚本中英双语提示规范

本规则只约束 skill 内自带脚本的用户可见输出，不扩大到 Codex / Claude 对话回复或仓库说明文档。

## 适用范围

- `skills/*/scripts/` 下脚本输出给用户看的提示、错误信息、状态摘要和交互引导。
- 初次添加账号备份、提示是否运行测活命令、测活失败兜底、补充命令引导等脚本文案。
- 共享数据文件中会被上层 skill 展示给用户的错误字段或状态说明。

## 不适用范围

- Codex / Claude 在对话窗口中给用户的常规回复，除非用户明确要求双语。
- README、AGENTS、AGENTSDOC 等说明文档本身，这些文档默认中文为主即可。
- 第三方工具的原始输出；如果不需要二次包装，不强制改写为双语。
- 内部字段名、配置 key、命令行参数、文件名和目录名，这些内容应保持英文，避免影响 JSON、CLI 和脚本兼容性。

## 输出规则

- 用户可见输出采用“中文（English）”双语形式，例如：`已保存 profile (Saved profile)：architect`。
- 错误信息来自上游工具时，应保留原始英文报错，并补充简短中文解释，方便排查。
- 不要在脚本中直接抛出仅有英文的报错；至少包装一层中文说明，让用户能直接理解发生了什么。
- 共享数据文件中的可读错误字段如会被展示给用户，应同时保存原始英文内容和中文解释。
- 双语补充应简短，不要为了翻译把脚本输出变成长篇说明；复杂排障步骤可以指向说明文档或给出下一条建议命令。
